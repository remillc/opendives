# Mock-ups (source)

Copies of the boards of the design canvas on claude.ai ([online](https://claude.ai/artifact/Jpuj8pGER3xz8n383JvYep), private), for the coding agent. They are the HTML source of the boards: read them for structure, texts, sizes and colours. They need the canvas runtime to render, so they do not display correctly when opened alone. UI texts are in French, the reference language.

Only the boards that tasks in `docs/agent-inbox.md` refer to are copied here; they are refreshed when the canvas changes. When a mock-up and `docs/ui-specification.md` disagree, the specification wins.

| Files | Screen |
| --- | --- |
| `appbar-tiroir-{ios,android}[-ouvert].dc.html` | Top bar and side menu, closed and open |
| `compte-{ios,android}-{connecte,sans-compte}.dc.html` | Account screen, signed in and without an account |
| `detail3-{ios,android}[-sombre].dc.html` | Full dive detail, light and dark |
| `detail2-{ios,android}-menu.dc.html` | Dive detail with the top-right menu open |
