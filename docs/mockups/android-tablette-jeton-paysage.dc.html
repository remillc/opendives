Créer un jeton d’accès

OpenDives se connecte à votre dépôt avec un jeton d’accès personnel, jamais avec votre mot de passe. Créez un jeton limité à ce seul dépôt, avec le droit de lire et d’écrire son contenu et rien d’autre, et une date d’expiration. Les libellés ci-dessous sont ceux de l’interface anglaise de chaque site.

Un jeton « fine-grained » peut être limité à un seul dépôt.

  1. Connectez-vous à GitHub, puis ouvrez Settings (menu de votre photo de profil).
  2. Tout en bas de la colonne de gauche, ouvrez Developer settings.
  3. Ouvrez Personal access tokens, puis Fine-grained tokens, puis touchez Generate new token.
  4. Token name : un nom reconnaissable, par exemple OpenDives.
  5. Expiration : choisissez une date proche, par exemple dans 90 jours. À cette date le jeton cesse de fonctionner et vous en créez un nouveau.
  6. Resource owner : votre compte, ou l’organisation qui possède le dépôt.
  7. Repository access : choisissez Only select repositories, puis le dépôt de votre carnet.
  8. Permissions : dans Repository permissions, réglez Contents sur Read and write. N’ajoutez aucune autre permission.
  9. Touchez Generate token, puis copiez le jeton.
Ouvrir la page des jetons de GitHub

Collez ensuite le jeton dans OpenDives, avec votre nom d’utilisateur. Le jeton n’est montré qu’une fois par le site : copiez-le avant de quitter la page.
